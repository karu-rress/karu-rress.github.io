About Me

"Unlocking the era of self-evolving software through the power of PL and AI."

"What if software could autonomously optimize performance and patch its own security flaws?"

Driven by a deep interest in how software improves human lives, I am dedicated to researching the fundamental sciences that underpin all programming. I believe we must move beyond human-led detection of errors and vulnerabilities toward an era where software can autonomously repair and evolve. My goal is to develop a framework that automates static code analysis and dynamic binary analysis using AI to preemptively eliminate security threats and optimize performance. Through this, I aim to maximize productivity for developers while ensuring that users can rely on highly secure and stable services.

I am committed to building a system that identifies legacy code and patches it with modern standards, ensuring automated resource management and a reduction in developer error. By automatically introducing validation layers to counter common exploits like BOF and SQL Injection, I intend to bridge the gap in software security. I envision a universal framework, independent of specific programming languages, that operates seamlessly from the IDE to deployment. Through this 'self-evolving' software model, I will work toward a future where programs continuously improve their own security and performance, revolutionizing the way we interact with the digital world.
